# 后台成员统计与老用户状态

`/admin` 保留原四个卡片，新增男女比例与老用户状态；超级管理员可从老用户卡片进入 `/admin/members/legacy`。

- 男女统计当前、正常、审核通过且关联有效 Auth 账号的成员，只计本人填写的男/女；不计官方 `ZXS_000`、其他性别、未填资料及关闭/历史档案。
- 老用户底表复用 `private.member_number_roster()`，排除官方号后为 247 人。仅通过已经分配的预留编号关联当前成员；新查询不会按姓名绑定账号，也不将编号归属视为本人身份验证。
- 已激活指对应当前账号正常、关联有效 Auth 账号且有成功登录记录，与审核结果独立。未关联账号显示待核实，不等同于未注册；关闭、匿名化及退役编号不计激活。
- 表格展示审核结果，不将面试日期、评分或预留编号误作面试通过。最近登录来自 Auth 的 `last_sign_in_at`，统一日本时间；不是最近访问或在线状态。
- 普通管理员仅可读聚合统计。名单姓名、编号及登录时间仅超级管理员可读，私有查询函数不开放给客户端；数据库和服务端均检查权限。查询失败明确显示失败，不伪造零人数。
