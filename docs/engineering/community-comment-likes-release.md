# 社区评论点赞

树洞和相册详情中的普通评论、子回复各自支持点赞与取消。每个会员最多保留一个赞，允许自赞但不通知自己。列表评论预览与原有帖子点赞保持原样，评论按时间排序。

## 数据与通知规则

- 独立 `community_comment_likes` 表；客户端仅能读本人记录，写入只能经过认证的 `community_set_comment_like`。接口接受目标状态，重复请求不增加计数。
- 评论 `like_count` 与单调递增的 `like_version` 在同一事务维护。`community_get_comment_like_states` 用单条查询读取本人状态、数量、版本；每批最多 1000 个 ID。界面忽略过期版本，失败回滚可信状态。
- `comment_like` 按接收会员与评论唯一聚合，数量为有效的非自赞人数，不公开点赞者昵称、头像或名单。人数不根据可变拉黑列表增减，避免聚合数成为身份探测工具；被拉黑者的事件不新建通知。
- 已存在通知只改人数，不重置已读状态或创建时间。归零保留已读记录，但通知列表及未读数都过滤零值，取消再赞复用该记录。沿用现有 90 天保留期；过期清理后后续点赞可以创建新的通知，任一时刻仍至多一条。
- 遵守现有点赞通知偏好、账号有效性、禁言/封禁、内容可见性与匿名作者保护。匿名内容不会通过真实作者的拉黑关系改变操作成功/失败。
- 隐藏/删除帖子、隐藏根评论同步隐藏受影响通知；正常子回复在根评论由作者删除后仍可互动。内容恢复只恢复已有通知数量，不重新提醒。
- 评论/帖子物理删除清理关联点赞与评论赞通知；账号匿名化撤销其发出的评论赞并重算数量，清理其收到的评论赞通知。历史帖子点赞策略不变。

## 验证

```sh
pnpm test:unit
pnpm typecheck
pnpm lint
pnpm build
PGLITE_MODULE=/path/to/@electric-sql/pglite/dist/index.js node supabase/audits/community-comment-likes-pglite.mjs
```

PGlite 运行真实 PostgreSQL SQL、RLS 和权限函数，使用隔离 fixture，不连接业务库；它是单连接测试，不等于多连接并发压力测试。锁顺序统一为评论、帖子、通知，帖子状态触发器只同步通知、不锁评论，避免与现有评论删除/帖子计数路径形成反向锁链。

浏览器验收应覆盖普通评论/子回复的准确目标、连续点击、取消、失败回滚、禁言、匿名显示、中日文、手机布局；SQL验收覆盖多会员聚合、已读后增长、归零重赞、RLS、屏蔽/删除/恢复与账号生命周期。

## 发布

增量文件：`supabase/migrations/20261002153140_community_comment_likes.sql`。

先核对目标项目和实际 catalog：旧通知类型约束必须保留报名/匹配类型，新评论点赞表与版本列尚未存在。仓库 numeric 旧迁移与正式库 timestamp 历史不一致，不能从主目录 `db push --include-all` 或修复/覆盖旧历史。可在临时隔离目录用 CLI `migration fetch` 只读获取该目标已应用历史，复制本次唯一增量文件，确认 `db push --dry-run --skip-vault` 只列该文件后执行。保留工作区原有 Preview 链接。

数据库升级应先于新应用发布。发布后核对迁移历史、两项 RPC、计数/版本列、聚合唯一索引、RLS 和客户端 DML 撤权；没有真实登录玩家的操作证据时，不能将本地浏览器 fixture 称为线上完整端到端验证。

### 2026-10-03 发布核验

- 全量单测 137 个文件、1003 项通过；类型检查、ESLint、生产构建通过。
- PGlite 的 21 组数据库回归通过，覆盖聚合、取消、自赞、权限、通知偏好、内容状态和账号匿名化。
- 本地浏览器使用实际评论组件验证主评论/子回复目标、取消、失败回滚、禁言、中日文；390px 手机视图无横向溢出，点赞按钮点击区域为 44×44px。服务端调用为测试替身，未将其视为正式登录玩家的端到端验收。
- 正式库 `wjjhprflldvclulistcx` 已应用上述唯一增量，原 Preview 链接保持不变。发布后确认迁移记录、RLS、两个 RPC、聚合唯一索引和各角色权限；计数不一致及重复通知组均为 0。
- Security Advisor 总数发布前后均为 193：撤销旧通知偏好 helper 的两项公开执行警告，新增两项已登录用户可执行 SECURITY DEFINER 的提示，分别对应有意公开的读/写 RPC。两接口均校验当前用户、限定可访问内容，固定空 search_path，匿名用户不可执行；未出现新增的 RLS 缺失或匿名执行问题。
