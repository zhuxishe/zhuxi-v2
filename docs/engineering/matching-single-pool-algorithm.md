# 覆盖优先与单一多人池算法

本批仅修改后台算法正确性。新运行使用 `max_coverage_split:2`；`match_sessions.algorithm` 仍为 `max_coverage_split`，继续触发既有快照标记。旧快照与结果不回填、不重算。版本兼容迁移仅扩展封存函数的算法版本白名单，保留 v1，其他资格、配置、隐私和发布检查不变。

## 已确定的规则

- 每次仍从本轮完整报名大池复核资格，已有有效匹配者不会被排除；继续边收集边运行。
- 每次算法运行生成互不重复的双人结果，以及最多一个多人结果。多人至少 3 人，不再上限 6 人，不拆子组。只有整池共同拥有至少一个时段、没有任何禁止同组关系，且每人的性别偏好最终得到满足，才能作为有效多人结果。
- 双人单选者只进入双人， 多人单选者只进入多人池；都可以者可在两种类型之间调剂。
- 禁忌沿用标签完全相同的判定；黑名单与冷却仍不可放松。多人性别沿用每人至少一位其他成员符合，未知性别继续放行。构池时不能套用双人性别要求提前拒绝一个可由后续成员补齐的组合。
- 取消“不接受新手且对方活动次数为 0”的硬否决；问卷字段、已有答案和经验相近度评分均保留，不因该接受度字段新增扣分。
- 不增加时间过期过滤、低分门槛或新权重，不接入新的互评来源。本批不修改重开与导入规则。

## 选择目标与评分

对完整方案依次比较：覆盖人数更多、普通重复关系更少、按人数加权的原因子得分更高；完全相同时倾向更大的多人池，再使用保存的输入顺序稳定选择。

普通重复：双人中的一条 `avoid` 关系算一次，多人池内每条 `avoid` 关系算一次。普通重复可以为覆盖而接受；黑名单、冷却、禁忌不因此放松。双人原有重逢 +30／普通重复 -20 处理保留。

多人先校验整池合法，再用原八因子对全体两两成员评分并完整平均。3 人计算 3 对，13 人计算 78 对，不能跳过被双人类型规则否决的关系而得到零分或不完整均分。权重与各因子原计算方式不变。整批质量为双人得分乘 2，加多人均分乘池人数；比较覆盖相同方案时避免组数造成累计分偏置。多人分数仅显示时四舍五入一位，选方案使用未舍入值。

## 求解与可复现边界

`coverage-plan.ts` 预先计算所有可行双人边及多人共享关系；不再先锁定双人再处理剩余者。18 人以内枚举全部可行单一多人池，剩余双人用子集动态规划，按上述目标求精确结果。

超过 18 人使用确定性预算搜索多人池，对已评估方案的剩余双人使用一般图最大基数匹配，再作不降低覆盖的局部择优。每个共同时间先评估代表方案，剩余预算按时段分配。性别无法被同一时段任何合法成员满足的人仅不能进入该时段的多人结果，仍在原候选和未匹配统计中。

大池模式是覆盖优先的受限搜索，不能宣称所有规模均达到全局最优，也不能保证重复和得分全局最优。预算固定在算法版本中，不按运行时间或随机数截断，保证同一输入与版本可复现。最终结果仍须验证整池合法性、成员不重复及人数守恒。
