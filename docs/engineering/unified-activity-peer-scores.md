# 统一活动评分与后台长期合拍分试算

本功能按活动版本分流。迁移 `20261117090302_unified_activity_peer_scores.sql` 将迁移时已经存在的每个活动（包括草稿）登记为旧版；只有此后新建活动使用统一单项规则。本文不是生产数据库已迁移的证明。

## 2026-11-23 新建活动规则

新规则由迁移 `20261123103221_unified_peer_confirmation_and_requests.sql` 固定在活动创建时。迁移前已有的活动（包括草稿）继续使用各自的 `legacy` 或 `unified_v1` 规则，重开、补评、修改日期均沿用该活动版本。迁移后新建活动使用 `unified_v2`。

- 新版活动在网页端评价。小程序代码仅预留指向本场网页版的提示，本次发布范围为网页和数据库。玩家从本场参与名单选择实际交流过的人，确认互动后提交 1–5 分（含半分），文字选填。1 分可以单独保存，举报可以单独提交。确认记录仅随成功评分保存。同一人同一场对同一对象修改评分只更新原记录。
- 在正常窗口内可修改。评分截止后，每位仍欠评且符合资格的参与者可补一条，完成后返回报名。报名检查继续以每场活动的个人提交状态判断。
- “申请不再匹配”进入后台「匹配管理 → 不再匹配申请」，由工作人员核对并人工处理。工作人员填写处理说明和原因，申请人可查看自己申请的状态。申请、评分和举报分别记录。处理申请不会自动调整已发布的匹配。
- 后台长期分沿用有效单项评分，先在每位评价人内跨场求平均，再对不同人的均值等权平均。旧五项保留原用途。2 位评价人且覆盖 3 场受评活动仅作为未来公开资格。本期会员主页继续展示运营维护的合拍分，匹配仍按既有两人互评规则计算。
- 历史兼容说明和 11 月 17 日的验收记录见下文。其中“1 分须关联举报”描述的是第一版单项活动。

## 第一版保护范围

- 竹溪社11月匹配活动的五项表单、入口、提交、完成状态以及结束后评价流程保持原规则。活动结束时间不是新版切换时间。
- 其他存量活动沿用各自现有规则，既有单项活动不自动改变交互或配置。
- 前端个人合拍分继续读取现有运营指标，初始值、人工调整及发布状态不由试算覆盖。
- 已生成的匹配输入快照、结果、问卷、A/B/C/D及小程序代码不修改。
- 保留现有中文、日文1分提示原文，包括“默认对方存在恶意行为”“双方或许只能保留一位”。这些提示不产生自动封禁或自动拒配。

## 新版行为

网页版及移动浏览器沿用现有活动互评界面，1–5分、0.5分刻度、文字选填、不预填。匹配卡和旧评分URL根据真实活动版本进入对应入口；未迁移数据库只在确认为新RPC不存在时继续旧行为，其他错误不能伪装成没有评分。

新版固定报名活动默认同步有效报名，不等待人工逐个核实。后台可处理误录、缺席及实际到场补录。手动移除优先于自动报名同步；仅迟到或普通资料修正不应移除成员。新匹配活动的自动名单以当前正式发布结果为基础，工作人员可补录实际参与者。普通报名取消停止新的评价资格，但不直接抹去已保存的有效历史评分。

新活动按活动配置自动初始化互评时间，默认截止为整场活动结束后7天，可由后台调整。匹配活动还必须满足结果已正式发布、本人在有效参与范围内。旧活动的时间设置不变。

1分必须关联本场本人对同一对象的举报。首次评分或改为1分沿用现有两次确认和举报流程；评分与本次举报一起成功或一起失败。新版中已有1分且有关联举报时，仅改评论可复用举报，不反复要求同一份举报。举报不自动作废评分；管理员核查后另行处理是否拒配。

正常截止前可修改评分，按同一活动/评价人/被评价人的唯一记录更新。截止后欠评者可补交一次，已完成后不能继续通过补评入口新增或编辑。评分完成状态和评分是否进入个人试算分别处理，后续审核不自动重新产生评分义务。

## 后台试算

成员360的“活动与匹配”页面增加只读试算卡片。每位评价人跨活动的有效评分先求平均，再对不同评价人的均值等权平均；只在最后展示一位小数。不衰减、不加基础分，无有效评分时显示无数据。

数据来源是有效的 `round_peer_reviews`，包括已有单项活动记录。排除测试、匿名化、明确无效及已删除活动；不因正常退会或后来取消报名而删除真实历史意见。旧 `mutual_reviews`、人工合拍分、A/B/C/D、面试及人格分不进入该计算。

卡片显示不同评价人数、收到评分的活动数、记录条数及可追溯来源。2位不同评价人且覆盖3场活动只标记为未来公开样本资格；本次不公开、不影响个人匹配优先级。管理员不能手填覆盖试算结果。RPC未部署时提示尚未配置，读取失败时显示失败，均不影响其他成员资料。

## 匹配与报名

新版单项评价延续现有两人活动互评软评分，不转成旧1分拒配或双5冷却。旧活动仍保留旧用途。既有匹配快照和已发布结果不重算。

新旧评价均可完成各自活动的报名评分要求。旧五项不进入个人试算，不意味着用户需要重评。未开放、暂停、无对象、管理员免除以及已成功报名的保护沿用现有规则。
